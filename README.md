# Telegram-бот «Ведущая чакра»

## Установка
1. Установите Python 3.10+.
2. `pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env`.
4. Укажите токен Telegram-бота.
5. Поместите изображения `chakra_1.jpg` ... `chakra_7.jpg` в папку `images/`.
6. Запустите: `python bot.py`.

Методика теста и основное содержание результатов встроены на основе загруженного документа, начиная с 12-й страницы.
