# Chakra Bot — версия без оплаты

В этой версии расширенный PDF выдаётся сразу, без Telegram Payments и без `TELEGRAM_PAYMENT_PROVIDER_TOKEN`.

## Что изменено

- Убрана проверка оплаты и весь платёжный flow.
- Кнопка «💎 Расширенный PDF» сразу формирует и отправляет отчёт.
- Короткие ответы теста обрезаются до 38 символов, чтобы кнопки были компактнее.
- В рекомендации добавлены расширенные разделы по **здоровью, отношениям и деньгам** на основе методички «День 1», страницы 18–38.
- В PDF добавлен подробный разбор ведущей чакры.
- В PDF добавлена визуальная JPG-энергокарта с фактическими оценками пользователя.
- Для каждой чакры со значением **ниже 3** в PDF добавляется сжатая выдержка рекомендаций: здоровье, отношения, деньги.
- Для анализа «Сферы жизни» добавлены конкретные рекомендации на основе двух наиболее слабых чакр каждой сферы.
- В PDF используются изображения чакр из `images/chakras/`.
- Добавлена зависимость Pillow для создания JPG-энергокарты.

## Railway

Обязательная переменная:
- `TELEGRAM_BOT_TOKEN`

Опционально:
- `ADMIN_IDS`
- `INSTAGRAM_URL`
- `DATA_DIR`

Платёжные переменные больше не нужны.

## Запуск

`python bot.py`


## Персональный PDF v2 — полная автоматическая сборка

После завершения теста бот:
1. сохраняет результат ведущей чакры;
2. запрашивает имя клиента, которое будет напечатано на титульном листе;
3. автоматически определяет вариант титульного листа по имени: женский, мужской или универсальный;
4. просит пройти энергокарту;
5. после завершения энергокарты автоматически собирает единый PDF из результатов теста + энергокарты + анализа сфер;
6. автоматически отправляет PDF в Telegram.

В PDF:
- две версии титульного листа — женская и мужская;
- семь иллюстраций чакр, автоматически выбираемых по ведущей чакре;
- визуальная энергокарта;
- отдельная страница для каждой из 7 чакр;
- три точки роста;
- анализ здоровья, отношений и денег;
- персональный итог и недельный фокус.

Определение пола по имени является эвристическим. Для редких/неоднозначных имён используется универсальный титульный лист.

### Визуальные материалы

В архив добавлена папка `images/source_visuals/` с исходными визуальными материалами проекта. Рабочий генератор отчёта использует отдельные иллюстрации `images/chakras/` для каждой из 7 чакр и автоматически выбирает иллюстрацию ведущей чакры. Титульный лист выбирается по определённому профилю клиента, а содержание рекомендаций — по ведущей чакре и показателям энергокарты.
