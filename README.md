# Telegram-бот «Ведущая чакра»

## Локальный запуск

1. Установите Python 3.10+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env`.
4. Укажите в `.env` значения `TELEGRAM_BOT_TOKEN` и при необходимости `ADMIN_IDS`.
5. Запустите:
   ```bash
   python bot.py
   ```

## Запуск на Railway

Файл `.env` намеренно не загружается в GitHub и Railway. Это сделано для защиты токена бота.

В Railway откройте сервис бота → **Variables** и добавьте:

- `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота;
- `ADMIN_IDS` — ваш Telegram ID (можно указать несколько ID через запятую).

После добавления переменных выполните **Deploy** или перезапустите сервис. Проект запускается командой:

```bash
python bot.py
```

## Исправление переносов строк

В `bot.py` исправлено использование `\\n`: теперь сообщения используют реальные переносы строк `\n`, поэтому в Telegram больше не должны отображаться буквальные символы `\\n`.

## PDF

Для расширенного отчёта используется ReportLab. При наличии изображений `images/chakra_1.jpg` ... `images/chakra_7.jpg` они автоматически добавляются в отчёт.

## Новые возможности

### 🌿 Рекомендации «из минуса в плюс»
После основного теста бот показывает:
- признаки состояния в минусе;
- практические шаги восстановления;
- качества, которые формируют ресурсное состояние.

### 🗺 Личная энергокарта
Отдельная анкета содержит 21 вопрос — по 3 утверждения для каждой из 7 чакр. Пользователь оценивает каждое утверждение по шкале от 1 до 5, после чего получает карту состояния всех чакр и персональные первые шаги для зон с низким ресурсом.
