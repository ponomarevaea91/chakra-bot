# Chakra Bot — универсальный персональный PDF-отчёт

Telegram-бот для теста ведущей чакры, 21-вопросной энергокарты и автоматической сборки персонального PDF.

## Что исправлено

- После завершения теста бот просит только имя клиента — без примеров конкретных имён.
- Можно вводить любое имя, фамилию или ФИО.
- Текст PDF сделан универсальным и подходит и женщинам, и мужчинам.
- Для визуального оформления сохранены женский и мужской варианты обложки; при неоднозначном имени используется нейтральная универсальная обложка.
- Ведущая чакра автоматически определяется по результатам теста.
- После завершения энергокарты PDF автоматически собирается по результатам обоих этапов.
- В отчёт автоматически подставляется иллюстрация ведущей чакры и иллюстрации всех 7 чакр.
- Рекомендации учитывают ведущую чакру и показатели энергокарты.
- Добавлены команды `/test`, `/energy`, `/energymap` для надёжного продолжения сценария.
- Кнопки меню работают как с эмодзи, так и без них.
- Исправлен раздел «💎 Мои отчёты»: последний готовый PDF можно открыть повторно.
- Добавлена нейтральная обложка для неизвестного/неоднозначного пола.
- Существующая SQLite-база мигрируется без удаления старых данных.

## Сценарий

1. Пользователь нажимает «Пройти тест».
2. Отвечает на вопросы и получает ведущую чакру.
3. Вводит имя клиента.
4. Нажимает «Энергокарта» и отвечает на 21 утверждение по шкале 1–5.
5. Бот автоматически формирует и отправляет PDF.
6. Готовый отчёт доступен через «Мои отчёты» и «Мой результат».

## Структура PDF

- титульный лист;
- ведущая чакра и её подробный разбор;
- персональная энергокарта;
- отдельные страницы всех 7 чакр;
- 3 главные точки роста;
- анализ здоровья/ресурса, отношений и денег/реализации;
- рекомендации;
- персональный вывод и фокус на неделю;
- пояснение ограничений методики.

## Запуск

Переменная окружения:

`TELEGRAM_BOT_TOKEN=...`

Опционально:

`DATA_DIR=...`
`ADMIN_IDS=...`
`INSTAGRAM_URL=...`

Проект рассчитан на запуск через Railway согласно `railway.toml`.
