# Chakra Bot — обновлённая версия

## Возможности
- тест на ведущую чакру;
- энергокарта по всем 7 чакрам (21 вопрос);
- рекомендации для перехода из «минуса» в «плюс»;
- анализ сфер: здоровье и ресурс, отношения, деньги и реализация;
- персональный PDF с кириллицей и данными энергокарты;
- 7 JPG-изображений чакр;
- история результатов;
- кнопка записи на консультацию в Instagram;
- Telegram Payments: после успешной оплаты бот автоматически выдаёт PDF;
- базовая воронка после результата.

## Важное про оплату
Для реального приёма платежей необходимо подключить платёжного провайдера в Telegram и добавить его токен в Railway:
`TELEGRAM_PAYMENT_PROVIDER_TOKEN`.
Без этого токена бот не сможет принять настоящий платёж на расчётный счёт.

## Railway
1. Загрузите содержимое папки в корень GitHub-репозитория.
2. Добавьте `TELEGRAM_BOT_TOKEN`.
3. Для постоянной базы создайте Volume `/data`.
4. Добавьте `DATA_DIR=/data`.
5. Для платного PDF добавьте `TELEGRAM_PAYMENT_PROVIDER_TOKEN`.
6. Railway запускает `python bot.py`.
